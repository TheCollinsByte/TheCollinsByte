# Hi, I'm Collins 👋

**Senior Software Engineer** · Arusha, Tanzania · Founder of [KwaWingu](https://kwawingu.com)

I build backend-heavy products that handle real money and real customers: booking engines, payment integrations, multi-tenant SaaS and WhatsApp AI agents.

### What I work on

- **KwaWingu**: a multi-product SaaS platform for East African tourism and hospitality (Tours, Stay, Dine, Rentals, QR), with a versioned public developer API
- **Payments**: mobile money and card gateway integrations, including the open-source [Mobile-Payments-Library](https://github.com/KwaWingu/Mobile-Payments-Library) for Tanzanian mobile money
- **WhatsApp AI agents**: conversational ordering and quoting built on the WhatsApp Business API and LLMs
- **Client websites**: fast, SEO-ready Next.js sites for safari operators, lodges and hotels, powered by the KwaWingu Tours API

### Tech I use

- **Backend:** Java 21 · Spring Boot 3 · GraphQL · REST · PostgreSQL · Flyway · Redis · Go
- **Frontend:** Next.js · React · TypeScript
- **Infrastructure:** Cloudflare (Workers, R2, Stream) · Docker · AWS · Linux · GitHub Actions
- **Mobile:** Flutter

### Open source

- [KwaWingu/Mobile-Payments-Library](https://github.com/KwaWingu/Mobile-Payments-Library): Java 21 SDK for Tanzanian mobile money (M-Pesa, Airtel Money, HaloPesa, Mixx by Yas)
- [KwaWingu/kw-wp-plugin](https://github.com/KwaWingu/kw-wp-plugin): WordPress plugin that syncs a KwaWingu Tours catalogue into a tour-operator website
- [rssagg](https://github.com/TheCollinsByte/rssagg): RSS aggregator REST API in Go with PostgreSQL
